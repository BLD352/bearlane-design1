# ThreadVault

ThreadVault is an embroidery-focused production operating system for custom apparel teams.

## Sprint 1 Scope

- Authentication
- Dashboard
- Customer Vault
- Upload Library
- Production foundation

## Folder Structure

- `MASTER.md`: Product master specification.
- `docs/SPRINT_1_ARCHITECTURE.md`: Sprint architecture and implementation sequence.
- `prisma/schema.prisma`: Initial Prisma schema for workspace-isolated MVP models.

## Getting Started

1. Install dependencies in your Next.js app workspace.
2. Configure PostgreSQL and set `DATABASE_URL`.
3. Run Prisma migration commands.
4. Implement Sprint 1A dashboard shell, then 1B and 1C.
